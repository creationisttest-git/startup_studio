# Startup Studio

**https://startupstudio.projectfreedom.xyz**

Drop an idea on a kanban board. Startup Studio's AI agents will be your team and build a real v1 in days. You spend your time finding out if anyone wants it.

# Why this exists
I'm a solo founder with a limited budget. My focus is finding the ideas that will show traction in the real world, as fast as possible.

## What you get
Seventeen agent roles that run as one product team, covering product, engineering, design, content, marketing, operations, QA, security, review, and the health of the studio itself. One roster, shared across every project, layered with a short page of what is different about each one, so a lesson learned on any of them reaches the rest.

Some of the rules are enforced by the tooling rather than written down and trusted:

- Only the QA role can move a ticket to user acceptance testing, and only with test notes written first.
- Nothing is released without a changelog entry.
- A ticket cannot be closed while a question on it is unanswered.
- A large piece of work cannot start until an assessment carrying a verdict and a measure is recorded against it.

The front door itself is the method rather than the software: six leads argue a large idea from their own disciplines before it is built, and a verdict of no is a normal outcome. What the board enforces is that the record exists.

It runs on Claude Code today. That is a limitation of this tooling and not of the method.
